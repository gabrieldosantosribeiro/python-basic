# 🐍 Python Básico

## 📖 Sobre o projeto

Este repositório reúne uma coleção de **85 exercícios práticos em Python**, desenvolvidos durante um curso de programação no SENAI.

Os exercícios cobrem desde os conceitos fundamentais da linguagem até tópicos mais avançados, como **programação orientada a objetos (POO)**, com foco na prática e consolidação da lógica de programação.

Além disso, o projeto inclui o arquivo `notas.py`, que funciona como uma **referência rápida de sintaxe e funcionalidades**, útil para consultas no dia a dia durante o desenvolvimento.

---

## 🚀 Tecnologias utilizadas

* Python 3 (compatível com versões modernas da linguagem)

---

## 💡 Conteúdos abordados

* Variáveis e tipos de dados
* Estruturas condicionais (`if`, `else`, `elif`)
* Estruturas de repetição (`for`, `while`)
* Funções
* Listas, tuplas e dicionários
* Manipulação de strings
* Entrada e saída de dados
* Programação orientada a objetos (classes e métodos)

## 📦 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/gabrieldosantosribeiro/python-basico.git
```

2. Acesse a pasta do projeto:

```bash
cd python-basico
```

3. Execute qualquer exercício:

```bash
python 001.py
```

## 🎯 Objetivo

O objetivo deste repositório é servir como **base prática de aprendizado em Python**, utilizando exercícios para reforçar conceitos e desenvolver lógica de programação.

O arquivo `notas.py` complementa esse processo como um **guia rápido de consulta**, facilitando o uso da linguagem no dia a dia.
